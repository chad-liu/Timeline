# 日本歷史時間列表：從繩文時代到令和時代

日本歷史可以依照考古文化、古代國家形成、武士政權、幕府統治、近代化與現代日本等階段來理解。以下以年代、主要事件、政治制度與時代特色整理成一份完整的時間表，方便查閱、教學與製作歷史時間軸。

## 一、日本歷史主要時代總覽

1\. 史前時代

## 舊石器時代至彌生時代

約西元前 3 萬年－西元 300 年前後

從狩獵採集、繩文陶器，到稻作農業、金屬器與階層社會的形成。

2\. 古代國家形成

## 古墳、飛鳥、奈良、平安時代

約 3 世紀－1185 年

大和政權興起、律令國家建立、佛教傳入，以及天皇朝廷與貴族文化的發展。

3\. 武士與幕府時代

## 鎌倉、室町、安土桃山時代

1185－1600 年前後

武士掌握政治實權，幕府制度發展，歷經南北朝、戰國亂世與天下統一。

4\. 幕府統治與近代轉型

## 江戶時代

1603－1868 年

德川幕府統治、社會秩序穩定、商業與城市文化興盛，後期面臨西方列強衝擊。

5\. 近代與當代日本

## 明治、大正、昭和、平成、令和

1868 年－至今

明治維新、帝國擴張、第二次世界大戰、戰後民主化、經濟高速成長與當代社會轉型。

## 三、日本歷史重大事件年表

依年代排序，列出理解日本歷史時最值得掌握的轉折點。

1. 約西元前 300 年前後｜稻作文化擴展

   彌生文化逐漸發展，水稻農業促進定居生活、人口成長與社會階層形成。
2. 約 3－5 世紀｜大和政權發展

   大型古墳反映統治階層的權力與區域整合。
3. 538／552 年｜佛教傳入日本

   傳入年代存在不同說法；佛教逐漸影響政治、藝術與文化。
4. 645 年｜大化改新

   推動政治改革，朝廷進一步發展以天皇為中心的中央集權體制。
5. 710 年｜遷都平城京

   奈良時代開始，律令國家與佛教文化發展。
6. 794 年｜遷都平安京

   平安時代開始，京都成為長期的政治與文化中心。
7. 1185 年前後｜源平合戰結束

   源氏取得優勢，武士政權逐步確立。鎌倉幕府的建立年份也常以 1192 年標示。
8. 1274、1281 年｜蒙古襲來

   元朝與高麗方面的軍隊兩度進攻日本，均未能征服日本。
9. 1467 年｜應仁之亂

   戰亂加劇，成為戰國時代的重要起點之一。
10. 1543 年｜火繩槍傳入

    歐洲火器傳入日本，逐漸改變戰爭方式。
11. 1600 年｜關原之戰

    德川家康取得決定性勝利，為建立德川幕府奠定基礎。
12. 1603 年｜江戶幕府成立

    德川家康受封征夷大將軍，日本進入長期的幕府統治時期。
13. 1853 年｜培里艦隊來航

    美國艦隊抵達日本，對幕府施加開國壓力。
14. 1868 年｜明治維新

    政權轉移至明治天皇政府，日本開始大規模制度改革與現代化。
15. 1894－1895 年｜甲午戰爭

    日本與清朝交戰，日本取得勝利，東亞政治格局發生重大變化。
16. 1904－1905 年｜日俄戰爭

    日本擊敗俄羅斯帝國，國際地位提升。
17. 1931 年｜九一八事變

    日本關東軍進攻中國東北，開啟日本擴大侵略的重要階段。
18. 1937 年｜中日戰爭全面爆發

    日本對中國發動全面戰爭，戰事持續至 1945 年。
19. 1941－1945 年｜太平洋戰爭

    日本與美國等同盟國交戰，最終於 1945 年戰敗。
20. 1947 年｜日本新憲法施行

    確立國民主權、基本人權與和平主義等戰後憲政原則。
21. 1950－1970 年代｜經濟高速成長

    日本工業與出口迅速發展，成為世界主要經濟體之一。
22. 1989－1991 年前後｜泡沫經濟轉折

    昭和時代結束、平成時代開始，日本資產泡沫破裂後進入長期經濟調整。
23. 2011 年｜東日本大震災

    地震、海嘯及福島第一核電廠事故對日本社會造成重大影響。
24. 2019 年｜令和時代開始

    明仁天皇退位，德仁天皇即位，日本進入令和時代。

## 四、日本年號與西元對照

日本近代以來常使用天皇年號紀年。下表列出近代五個主要年號：

| 年號 | 起訖年份      | 年代特色         |
| -- | --------- | ------------ |
| 明治 | 1868－1912 | 維新與現代化       |
| 大正 | 1912－1926 | 民主政治與社會運動    |
| 昭和 | 1926－1989 | 戰爭、戰後重建與經濟成長 |
| 平成 | 1989－2019 | 泡沫經濟後的調整     |
| 令和 | 2019－至今   | 當代日本         |

例如，2026 年屬於令和 8 年。令和元年是 2019 年，因年號於該年 5 月開始，所以 2019 年 1 月至 4 月仍屬平成 31 年。

## 五、理解日本歷史的三條主線

政治主線：天皇、貴族、武士與現代政府

大和政權 → 律令國家 → 藤原氏攝關政治 → 幕府與武士 → 明治中央集權國家 → 戰後民主制度。

軍事主線：武士興起、戰國統一與帝國戰爭

平安末期武士崛起 → 鎌倉幕府 → 戰國群雄 → 德川統一 → 近代軍事擴張 → 二戰戰敗。

文化主線：佛教、和風文化與現代化

佛教傳入 → 奈良佛教 → 平安假名文學 → 禪宗與武家文化 → 江戶町人文化 → 明治西化 → 當代大眾文化。
