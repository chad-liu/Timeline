# Liu's Timeline

仿 [Timetoast](https://www.timetoast.com/) 的個人時間軸網站。目前收錄 **300 多條時間軸、1 萬多則事件**，涵蓋世界史、西方與東方歷史、音樂家、藝術家、思想家、科學家、文學家與經濟商業，其中近 190 條是人物生平。

**網站：https://liu-timeline.pages.dev/**

每條時間軸就是 `Data/` 裡的一個 Markdown 檔。網站是純靜態、唯讀的：要修改內容，直接編輯檔案即可。姊妹站是讀書筆記網站 [chad-liu.github.io/books](https://chad-liu.github.io/books/)，兩站以連結雙向互通（見[與 books 網站互通](#與-books-網站互通)）。

## 功能

### Dashboard（首頁）

- 上方頁簽切換類別，頁簽下的標籤再細分，例如「浪漫時期」「戰爭與革命」。
- 每條時間軸一張卡片，顯示封面、年代範圍與事件數。點卡片開啟，點 `•••` 選擇檢視方式。
- 右上角通往五個頁面：人名索引、人物關係圖、主題索引、年代對照、人物年表。
- 頂端的搜尋框是**全站搜尋**：輸入關鍵詞按 Enter，列出所有時間軸裡標題或內文符合的事件，依時間軸分組並標出關鍵詞，點事件直接開啟。用空白分隔多個關鍵詞時要全部符合；時間軸的標題、別名與標籤也算，所以「巴赫 萊比錫」會找到巴赫時間軸裡提到萊比錫的事件。標題符合的時間軸排在最前面。

### 時間軸的三種檢視

| 檢視 | 說明 |
|---|---|
| **橫向** | 時間尺加上自動堆疊、不重疊的事件卡片，時期以色帶顯示。滾輪以游標為中心縮放，拖曳平移，底部總覽列可拖曳，`⤢` 顯示全部。相隔超過一千年的空白會壓縮成斜紋斷層。 |
| **縱向** | 仿歷史簡表的直式版面，適合從頭讀到尾。 |
| **Grid** | 卡片格狀排列。 |

- 標題列的搜尋框可篩選事件；點事件或時期開啟詳細內容，`Esc` 關閉。
- **連續閱讀**：事件的詳細內容底部有「上一則／下一則」與目前位置（如 4 / 24），也可以按鍵盤 `←` `→` 切換。順序是畫面上顯示的事件依日期排列：有搜尋篩選時只在篩選結果裡切換，疊加比較時各時間軸的事件依日期穿插。背後的檢視會跟著移動到該事件，網址的 `&e=` 也同步更新。詳細內容底部的「同時期的其他時間軸 →」會跳到年代對照。
- **疊加比較**：點標題旁的 ▾ 打開清單。點名稱是切換時間軸，勾選核取方塊是把多條疊在一起；橫向檢視會分成泳道、共用同一條時間尺。
- **相關時間軸**：標題下方列出可跨類別跳轉的時間軸（如達文西 → 梅迪奇家族 → 文藝復興），也能一鍵疊加比較。手動連結寫在 frontmatter 的 `see:`，兩邊都會顯示；人物時間軸另外自動列出內文提到的人物與戰爭、時代（如蘇格拉底 → 伯羅奔尼撒戰爭），戰爭、時代頁面則列出提到它的人物。自動比對的結果僅供參考。

### 索引頁與關係圖

| 頁面 | 內容 |
|---|---|
| **人名索引** | 每位人物在其他時間軸被提到的事件，可依類別篩選、依生年或筆畫排序，也能搜尋人名、別名或家族。 |
| **人物關係圖** | D3 力導向圖。A 的時間軸提到 B（或反過來）就有一條實線，越粗代表提及的事件越多；人物提到戰爭、時代、家族等時間軸（至少 2 則事件）會連一條淡色細線到方塊節點；`see:` 畫成虛線。可依類別、最小事件數與跨類別篩選，輸入人名標示節點，點節點在側欄列出雙向提及數。 |
| **主題索引** | 黑死病、印刷術、法國大革命、冷戰等跨時間軸反覆出現的主題，依時間軸列出相關事件。 |
| **年代對照** | 選一個年份、十年或百年，列出所有時間軸在那段期間的事件與同時在世的人物及年齡。年份旁標出當時的中國帝王（明、清用年號紀年，如 1789 年為清乾隆 54 年）。西元前可輸入 `前221` 或 `-221`。 |
| **人物年表** | 所有人物的生卒年橫條，用來對照誰與誰同時代；沒有人物的年代壓縮成間隔。「依類別」按類別與標籤分組，「依時代」依出生年排序混排；點人名前的 ◎ 標出同時代的人（生存期重疊或前後 50 年內），再按「只看同時代」只留下這些人。 |

## 網址格式

目前的檢視都記在網址 `#` 之後，複製網址就能分享，重新整理也不會跑掉。

| 網址 | 開啟的內容 |
|---|---|
| `#c=音樂家&tag=浪漫時期` | Dashboard 的指定類別與標籤 |
| `#v=horizontal&t=Bach` | 一條時間軸的橫向檢視（`v` 可為 `horizontal`、`vertical`、`grid`） |
| `#v=horizontal&t=Bach\|Handel` | 多條時間軸疊加比較 |
| `#v=vertical&t=Voltaire&e=Voltaire-6` | 直接打開某則事件 |
| `#p=index`、`#p=topics`、`#p=lifespans` | 人名索引、主題索引、人物年表 |
| `#p=search&q=巴赫 萊比錫` | 全站搜尋，`q` 是關鍵詞（空白分隔，全部符合） |
| `#p=lifespans&g=era&sel=Confucius&only=1` | 人物年表「依時代」排列（`g=era`）、標出與孔子同時代的人（`sel`）、只看這些人（`only=1`） |
| `#p=graph&c=音樂家&w=2` | 人物關係圖：`c` 類別、`w` 連線至少幾則事件（預設 1）、`x=1` 只看跨類別連線 |
| `#p=years&y=1789&s=10` | 年代對照：`s` 為 `1`（單年）、`10`（十年）或 `100`（百年） |

## 新增與編輯內容

### 時間軸檔案

在 `Data/` 新增一個 `.md` 檔就是一條新的時間軸，檔名（不含副檔名）就是它的 id。最簡單的寫法：

```markdown
---
title: 巴赫生平
category: 音樂家
tags: [巴洛克時期]
born: 1685-03-21
died: 1750-07-28
---

# Periods
- 1685 ~ 1695 | 幼年@埃森納赫 | #7c4dff
  縮排的文字是這個時期的說明。

# Events
## 1685-03-21 | 出生
![](images/bach-1685-birth.png)
內文支援 Markdown。
```

- **日期**：可寫到日、月或年，也支援西元前（`前221`）、世紀（`14世紀`）、區間（`1642 ~ 1649`）與約略年代（`約七千年前`）。
- **人物**：寫了 `born`／`died` 的時間軸視為人物，事件自動加上年齡，並出現在人物年表、人名索引與 `people.json`。
- **其餘時間軸**（戰爭、時代、學派、主題）不寫 `born`／`died`，會進入 `timelines.json`。
- **完整格式**：所有 frontmatter 欄位（`color`、`cover`、`related`、`see`、`aliases`、`notNames`、`follows`、`squeeze`……）與日期寫法，見 [plan.md](plan.md)。

### 圖片

圖片放在 `Data/images/`，以 `images/檔名` 引用。目前都是 Wikimedia Commons 上的公有領域或 CC0 作品，每條時間軸開頭的 HTML 註解記錄了來源。封面（`cover:`）在 Dashboard 以 3:2 的框顯示、靠上對齊，最適合 640 × 427 的橫圖。

### 索引設定檔

`Data/index/` 底下的兩個檔案不是時間軸，而是索引頁的設定（格式見 [plan.md](plan.md)）：

- `people.md`：人名索引的補充名單，收錄沒有獨立時間軸、卻常被提到的人物（如梅迪奇家族成員、拿破崙）。
- `topics.md`：主題索引的主題清單，含比對用的關鍵詞與要排除的同字詞。

### 新增後的檢查

```bash
npm run scan:links   # 列出內文提到、卻沒有 see: 的人物與戰爭／時代配對
```

新增戰爭、時代、家族等時間軸後跑一次，看哪些人物提到它，想強調的補 `see:`；新增人物時間軸後也跑一次，看它提到哪些戰爭與時代。可加時間軸 id 只掃指定的時間軸，或加 `--all` 掃全部。

## 與 books 網站互通

兩個網站刻意不共用程式，只靠連結與兩份公開索引互通：

- **Timeline → books**：時間軸 frontmatter 的 `related:` 連到 books 的相關頁面，顯示在詳細頁。
- **books → Timeline**：網站建置時輸出 [`people.json`](https://liu-timeline.pages.dev/people.json)（人物的生卒年、類別、網址、延伸閱讀）與 [`timelines.json`](https://liu-timeline.pages.dev/timelines.json)（其餘時間軸的標題、類別、網址、延伸閱讀）。books 端的 `tools/add_timeline_links.py` 讀這兩份檔案，把每條時間軸的 `related:` 反推成頁面底部的「生平時間軸」與「相關時間軸」連結。

所以兩站的互連只需要維護時間軸的 `related:`。改了 `related:` 並部署之後，到 books 專案重跑一次腳本，再 commit books：

```bash
python tools/add_timeline_links.py
```

books 的資料夾編號會調整，`related:` 的連結必須對應 books 實際存在的檔案，調整後要掃一遍 `Data/` 裡所有 `chad-liu.github.io/books/` 連結。

## 開發與部署

需要 Node.js 22。

```bash
npm install
npm run dev      # http://localhost:5173，修改 Data/ 存檔後自動重新整理
npm test         # 單元測試（vitest）
npm run build    # 型別檢查並建置到 dist/
```

技術上是 Vite + React + TypeScript，關係圖用 `d3-force`、`d3-zoom`、`d3-drag`、`d3-selection`。`Data/*.md` 在建置時由 [vite-plugin-timelines.ts](vite-plugin-timelines.ts) 解析，前端拿到的是現成資料，不含 Markdown 或 YAML 解析器；事件內文渲染前一律經過 DOMPurify 清理。架構細節見 [CLAUDE.md](CLAUDE.md)。

### 部署

push 到 `main` 後，GitHub Actions（[deploy.yml](.github/workflows/deploy.yml)）先跑測試、再建置，最後用 wrangler 部署到 Cloudflare Pages（專案 `liu-timeline`）。repo 需要兩個 secret：`CLOUDFLARE_API_TOKEN`（權限：Account › Cloudflare Pages › Edit）與 `CLOUDFLARE_ACCOUNT_ID`。

舊網址 https://chad-liu.github.io/Timeline/ 仍由 GitHub Pages 提供，但只剩轉址頁（[redirect/](redirect/)，保留路徑與 `#` 之後的參數）與 `people.json`，讓舊連結不會失效；圖片只放在新網址。
