# Liu's Timeline

仿 [Timetoast](https://www.timetoast.com/) 的個人時間軸網站，收錄世界史、西方與東方歷史、音樂家、思想家、文學家、經濟商業等一百多條時間軸。

**網站：https://chad-liu.github.io/Timeline/**

每條時間軸都是 `Data/` 裡的一個 Markdown 檔。網站是純靜態、唯讀的：要修改內容，就直接編輯這些檔案。姊妹站是讀書筆記網站 [chad-liu.github.io/books](https://chad-liu.github.io/books/)，兩站以連結互通。

---

## 使用方式

### Dashboard（首頁）

- 上方頁簽切換類別（世界史、西方歷史、音樂家……），頁簽下方的標籤可再篩選，例如「浪漫時期」「戰爭與革命」。
- 每條時間軸一張卡片，顯示封面、年代範圍與事件數。點卡片開啟時間軸，點 `•••` 可以選擇用哪一種檢視開啟。
- 右上角的按鈕通往五個頁面：**人名索引**、**人物關係圖**、**主題索引**、**年代對照**、**人物年表**。

### 時間軸的三種檢視

| 檢視 | 說明 |
|---|---|
| **橫向** | 時間尺加上自動堆疊、不重疊的事件卡片，時期以色帶顯示。滾輪以游標為中心縮放，拖曳平移，底部總覽列可拖曳，`⤢` 顯示全部。相隔超過一千年的空白會壓縮成一段斜紋斷層。 |
| **縱向** | 仿歷史簡表的直式版面，適合從頭讀到尾。 |
| **Grid** | 卡片格狀排列。 |

- 標題列的搜尋框可以篩選事件。
- 點事件或時期會開啟詳細內容，按 `Esc` 關閉。詳細內容底部的「同時期的其他時間軸 →」會跳到年代對照頁。
- **疊加比較**：點標題旁的 ▾ 打開清單。點名稱是切換時間軸，勾選核取方塊則是把多條時間軸疊在一起；橫向檢視會分成泳道、共用同一條時間尺。

### 索引頁與關係圖

| 頁面 | 內容 |
|---|---|
| **人名索引** | 每位人物在其他時間軸被提到的事件。可依類別篩選、依生年或筆畫排序，也能搜尋人名、別名或家族。 |
| **人物關係圖** | 力導向圖（D3）：人物是節點，A 的時間軸（生平、作品）提到 B 或反過來，兩人之間就有一條連線，線越粗代表提及的事件越多。可依類別篩選、只看事件數達 2／3／5 以上的連線，輸入人名可標示節點；點人物會高亮他的連線並在側欄列出雙向提及數，滾輪縮放、拖曳移動，節點也可以拖動。 |
| **主題索引** | 黑死病、印刷術、法國大革命、冷戰等跨時間軸反覆出現的主題，依時間軸列出相關事件。 |
| **年代對照** | 選一個年份、十年或百年，列出所有時間軸在那段期間的事件，以及同時在世的人物和年齡。年份旁會標出當時的中國帝王，明、清用年號紀年（如 1789 年為清乾隆54年），其他朝代列出皇帝與在位年（如北宋 宋真宗，997–1022 在位）。西元前可輸入 `前221` 或 `-221`。 |
| **人物年表** | 所有人物的生卒年橫條，可以對照誰和誰同時代；沒有人物的年代會壓縮成間隔。 |

### 網址

目前的檢視都記在網址的 `#` 後面，複製網址就能分享，重新整理也不會跑掉。

| 網址 | 開啟的內容 |
|---|---|
| `#c=音樂家&tag=浪漫時期` | Dashboard 的指定類別與標籤 |
| `#v=horizontal&t=Bach` | 一條時間軸的橫向檢視（`v` 可以是 `horizontal`、`vertical`、`grid`） |
| `#v=horizontal&t=Bach\|Handel` | 多條時間軸疊加比較 |
| `#v=vertical&t=Voltaire&e=Voltaire-6` | 直接打開某則事件 |
| `#p=index`、`#p=topics`、`#p=lifespans` | 人名索引、主題索引、人物年表 |
| `#p=graph&c=音樂家&w=2` | 人物關係圖：`c` 是類別，`w` 是連線至少要有幾則事件（預設 1） |
| `#p=years&y=1789&s=10` | 年代對照：`s` 是 `1`（單年）、`10`（十年）或 `100`（百年） |

### 給其他網站用的人物資料

網站建置時會輸出 [`people.json`](https://chad-liu.github.io/Timeline/people.json)，列出所有人物時間軸的生卒年、類別、網址與延伸閱讀。books 網站就是靠它產生「連回時間軸」的連結。

## 編輯內容

### 時間軸檔案

在 `Data/` 新增一個 `.md` 檔就是一條新的時間軸，檔名（不含副檔名）就是它的 id。最簡單的寫法：

```markdown
---
title: 巴赫生平
category: 音樂家
tags: [巴洛克時期]
born: 1685-03-21
died: 1750-07-28
---

# Periods
- 1685 ~ 1695 | 幼年@埃森納赫 | #7c4dff
  縮排的文字是這個時期的說明。

# Events
## 1685-03-21 | 出生
![](images/bach-1685-birth.png)
內文支援 Markdown。
```

- **日期**：可以寫到日、月或年，也支援西元前（`前221`）、世紀（`14世紀`）、區間（`1642 ~ 1649`）與約略年代（`約七千年前`）。
- **人物**：寫了 `born`／`died` 的時間軸會被視為人物，事件會自動加上年齡，人物也會出現在人物年表、人名索引與 `people.json`。
- **完整格式**：frontmatter 的所有欄位（`color`、`cover`、`related`、`aliases`、`notNames`、`follows`、`squeeze`……）與日期寫法，見 [plan.md](plan.md)。

### 圖片

圖片放在 `Data/images/`，用相對路徑 `images/檔名` 引用。目前收錄的都是 Wikimedia Commons 上的公有領域或 CC0 作品，每條時間軸開頭的 HTML 註解都記錄了圖片來源。

### 索引的設定檔

`Data/index/` 底下的兩個檔案不是時間軸，而是索引頁的設定（格式見 [plan.md](plan.md)）：

- `people.md`：人名索引的補充名單，收錄沒有獨立時間軸、但常被提到的人物，例如梅迪奇家族成員、拿破崙。
- `topics.md`：主題索引的主題清單，每個主題列出比對用的關鍵詞，以及要排除的同字詞。

## 開發

需要 Node.js 22。

```bash
npm install
npm run dev      # http://localhost:5173，修改 Data/ 存檔後自動重新整理
npm test         # 單元測試（vitest）
npm run build    # 型別檢查並建置到 dist/
```

技術上是 Vite + React + TypeScript。`Data/*.md` 在建置時由 [vite-plugin-timelines.ts](vite-plugin-timelines.ts) 解析好，前端拿到的是現成資料，本身不含 Markdown 或 YAML 解析器。事件內文渲染前一律經過 DOMPurify 清理。架構細節見 [CLAUDE.md](CLAUDE.md)。

### 部署

push 到 `main` 後，GitHub Actions（[deploy.yml](.github/workflows/deploy.yml)）會先跑測試、再建置，最後部署到 GitHub Pages。
